# 피그매니저 프로젝트 인수인계

최종 갱신: 2026-10-10

## 1. 제품 방향

- 피그플랜, 피그온, 피그지오와 같은 돼지 농장 전산 프로그램을 만든다.
- 첫 대상은 모돈 중심 번식농장이다.
- 기술 방향은 Next.js App Router, TypeScript, Supabase, Vercel이다.
- 현재는 Supabase 연결 전이며 브라우저 `localStorage`와 예시 데이터로 업무 흐름을 검증하는 프로토타입 단계다.
- 핵심 번식 흐름은 `전입 → 초발정 → 교배 → 임신사고/분만 → 포유자돈 → 이유`다.
- 초기 요청에서 독립적인 양자 사이클은 제외했다. 양자전입·전출은 분만·포유·이유 기록 안의 두수 조정으로 관리한다.

## 2. 실행 방법

```powershell
npm install
npm run build
npm start
```

기본 주소는 `http://localhost:3000`이다. 새 빌드 후 기존 `next start` 프로세스를 종료하고 다시 시작해야 화면에 반영된다.

## 3. 현재 구현된 화면

### 대시보드

- 농장 현황, 관리 필요 항목, 번식 KPI, 월별 추세를 한눈에 보여주는 예시 화면
- 생산관리 1차 메뉴: 모돈개체관리, 웅돈개체관리, 비육돈그룹관리, 출하관리
- 대시보드 사이드바의 `생산관리`는 접기·펼치기 탭이며, 클릭하면 위 4개 관리 메뉴를 표시한다.
- 모돈개체관리 세부 메뉴: 전입관리, 초발정관리, 번식관리, 등지방관리, 도폐사관리
- 웅돈개체관리 세부 메뉴: 웅돈 전입관리, 웅돈 도폐사관리
- 비육돈그룹관리 세부 메뉴: 그룹등록, 두수관리, 그룹종료


### 비육돈그룹관리

- 1차 하위 메뉴: 그룹등록, 두수관리, 그룹종료
- 대시보드 메뉴와 각 실제 페이지 경로를 연결했다.
- 경로: 그룹등록 `/production/fattening-groups/registration`, 두수관리 `/production/fattening-groups/movement-intake`, 그룹종료 `/production/fattening-groups/closure`.
- `/production/fattening-groups/mortality`와 `/production/fattening-groups/outbound`는 별도 메뉴가 아니라 같은 두수관리 화면(`headcount-management-page.tsx`)을 폐사기록·전출 모드로 바로 여는 보조 경로다.
- 두수관리 한 화면에서 이동전입, 폐사기록, 전출, 출하를 선택해 등록한다.
- 그룹등록 필드: 그룹ID/그룹명, 시작일자, 시작장소, 성별, 품종, 시작일령, 입식두수 암·수, 비고
- 그룹ID/그룹명 중복 등록을 방지하고 시작일령·입식두수는 0 이상의 정수로 검증한다.
- 입식두수 암·수 합계는 1두 이상이어야 하며 화면에 자동 표시한다.
- 시작일자·품종·통합검색 조회, 시작일자·그룹ID·장소 정렬, 체크박스 선택 삭제 및 브라우저 `localStorage` 저장을 지원한다.
- 이동전입은 그룹등록에서 만든 그룹을 먼저 선택한다.
- 이동구분: 이유입식, 자돈구입, 농장내이동, 위탁(계열)전입, 부분이유입식
- 입식일자, 전입일령, 암·수 두수, 총생체중, 비고를 입력하며 현재두수에 누적 반영한다.
- 이동전입 정보에는 모돈번호를 입력하지 않으며, 농장내이동은 전출그룹을 필수 선택한다.
- 농장내이동은 전입그룹 현재두수에 더하고 전출그룹 현재두수에서 빼며, 전출그룹 암·수 보유두수를 초과하면 저장하지 않는다.
- 입식일자는 그룹 시작일자보다 빠를 수 없고 두수 합계는 1두 이상이어야 한다.
- 작업일·그룹ID·이동구분 정렬, 날짜·이동구분·통합검색 조회, 체크박스 선택 삭제를 지원한다.
- 폐사기록은 그룹등록에서 만든 그룹을 먼저 선택한다.
- 폐사 원인: 위축, 도태, 호흡기, 소화기, 관절/기립불능, 헤르니아, 신경증상, 기타
- 폐사일자, 폐사일령, 암·수 두수, 총생체중, 비고를 입력하며 폐사 두수는 그룹 현재두수에서 차감한다.
- 폐사 두수 암·수 합계는 1두 이상이어야 하며, 각각 선택 그룹의 현재 암·수 두수를 초과하면 저장하지 않는다.
- 폐사일자는 그룹 시작일자보다 빠를 수 없고, 폐사일령은 날짜 기준 자동 계산 후 직접 수정할 수 있다.
- 작업일·그룹ID·폐사원인 정렬, 날짜·폐사원인·통합검색 조회, 체크박스 선택 삭제를 지원한다.
- 전출 이동구분: 위탁(계열)전출, 농장내이동(자돈사), 농장내이동(육성사), 농장내이동(비육사), 농장내이동(검정사)
- 출하 이동구분: 자돈판매, 비육출하, 도태출하, 종돈판매, 기타
- 전출·출하는 이동일자, 일령, 암·수 두수, 생체중, 비고를 기록하며 현재두수에서 차감한다.
- 전출은 전출처/운송처, 출하는 거래처·금액·지육체중을 선택 입력할 수 있다.
- 이동전입·폐사·전출·출하 기록은 하나의 통합 목록에서 조회·정렬·선택 삭제한다.
- 그룹종료는 등록 그룹을 선택하면 현재일령, 입식두수, 폐사두수, 전출·출하두수, 현재 암·수 두수를 자동 집계한다.
- 현재 암·수 두수가 모두 0인 그룹만 종료할 수 있으며, 종료일은 그룹 시작일자와 마지막 두수 작업일보다 빠를 수 없다.
- 동일 그룹 중복 종료를 방지하고, 종료된 그룹은 두수관리의 대상 그룹과 농장내이동 전출그룹 선택에서 제외한다.
- 그룹종료 목록은 종료일·그룹ID 정렬, 날짜·통합검색 조회, 체크박스 선택 삭제를 지원한다. 종료 기록을 삭제하면 그룹은 다시 작업 가능한 상태가 된다.
### 출하관리

- `/production/shipping/grade-results`에 축산물품질평가원(eKAPE) 돼지 등급판정결과 조회 화면을 연결했다.
- 기본 화면은 농장식별번호와 판정일 시작·종료일만 선택하는 농장별 자동수집이며, 참든팜 농장식별번호 `500992`를 기본값으로 사용한다.
- 시작·종료 순번은 화면에 노출하지 않는다. 저장된 최근 순번을 기준으로 앞뒤 이력번호를 자동 탐색하고, 성공 시 최신 순번을 다음 조회 기준으로 저장한다.
- 자동 탐색은 한 번에 최대 120개 이력번호, 판정일 조회기간은 최대 1년으로 제한한다.
- 공공데이터포털 `축산물품질평가원_축산물등급판정확인서 발급정보`의 `confirm/issueNo`로 확인서 발급번호·발급일자를 찾은 뒤 `축산물 등급판정정보서비스`의 `confirm/pig`로 상세 등급판정자료를 조회한다.
- 확인서 발급번호·발급일자를 직접 넣는 개별조회도 보조 기능으로 유지한다.
- 공식 XML 응답에서 판정일, 성별, 도축장 관리지원·코드·주소, 도축번호, 등지방, 최종등급, 도체중, 경락가격, 돼지이력번호, 확인서번호, 박피구분을 변환한다.
- 조회한 결과는 기존 브라우저 `localStorage` 기록과 식별값 기준으로 합쳐 보관한다.
- 일반 인증키는 브라우저에 저장하지 않고 `EKAPE_GRADE_API_KEY`와 선택적 `EKAPE_ISSUE_API_KEY` 서버 환경변수에서만 읽는다.
- 상세조회 URL은 `EKAPE_GRADE_API_URL`, 발급정보 URL은 `EKAPE_ISSUE_API_URL`로 변경할 수 있다.
- `축산물품질평가원_축산물등급판정확인서 발급정보` API 활용승인이 완료되어 기존 인증키로 `confirm/issueNo`와 `confirm/pig` 연속 조회가 정상 동작한다.
- 등급판정 결과 목록은 선택한 판정일 범위로 필터링하고 한 페이지에 10건씩 표시한다.

### 보고서

- 대시보드 사이드바에 접기·펼치기 가능한 보고서 탭을 추가했다.
- 하위 메뉴와 실제 경로: 작업대장(`/reports/work-ledger`), 모돈리스트(`/reports/sow-list`), 작업지시서(`/reports/work-orders`), 교배(`/reports/mating`), 분만(`/reports/farrowing`), 생산분석(`/reports/production-analysis`), 비육돈(`/reports/fattening`), 출하분석(`/reports/shipping-analysis`).
- 교배와 비육돈은 접기·펼치기 카테고리다(2026-10-10 사용자 요청으로 작업지시서에서 하위 보고서 이동). 교배 하위: 교배목표 달성율(`/reports/mating/mating-target`), 비육돈 하위: 비육돈 주차별 현황(`/reports/fattening/fattening-weekly`). `/reports/mating`·`/reports/fattening`은 각 첫 하위 보고서로 이동한다. 메뉴 정의는 `report-menus.ts`의 `matingReportMenus`·`fatteningReportMenus`.
- 모든 보고서 페이지는 공통 보고서 사이드바를 사용한다. 사이드바의 작업대장·모돈리스트·작업지시서 카테고리는 해당 카테고리 화면 안에서 누르면 이동 없이 접기·펼치기만 하고, 다른 보고서 화면에서 누르면 해당 보고서로 이동하며 펼친다(`report-shell.tsx`의 `toggleCategory`). 상세 항목·계산식·조회 조건·출력 형식은 사용자 예시를 받아 메뉴별로 확정한다.
- 작업대장은 모돈 전입·교배·분만·포유자돈·이유·등지방·도폐사, 웅돈 전입·도폐사, 비육돈 그룹등록·이동전입·폐사·전출/출하·그룹종료의 브라우저 저장 기록을 하나의 목록으로 통합한다.
- 작업대장은 작업일 기간, 관리구분(모돈/웅돈/비육돈), 작업구분, 통합검색, 작업일 오름·내림차순과 10건 페이지 이동을 지원한다.
- 초발정과 임신사고는 공용 `localStorage` 저장 구조와 작업대장 연결을 완료했다.
- 작업대장을 누르면 다음 7개 하위 탭을 펼친다: 모돈전입대장, 웅돈전입대장, 초발정대장, 번식대장, 등지방 대장, 도폐사 대장, 비육돈 작업대장. 번식대장을 선택하면 교배대장이 열리고 화면 상단의 교배·임신사고·분만·포유자돈·이유 탭으로 이동한다.
- 메뉴 정의(`report-menus.ts`)에는 11개 경로가 있다. 보고서 화면 사이드바(`report-shell.tsx`)에는 7개만 보이고, 임신진단 사고대장·분만대장·포유자돈대장·이유대장 4개 경로는 숨긴 채 번식대장 상단 탭으로만 이동한다.
- 대시보드 사이드바(`app/page.tsx`)와 보고서 사이드바(`report-shell.tsx`)는 `report-menus.ts`의 공용 `sidebarWorkLedgerMenus`(7개)를 함께 사용한다. 숨김 대상은 같은 파일의 `hiddenBreedingLedgerKeys`에서 관리한다. 사용자 확인 결과 작업대장 하위 메뉴는 모돈전입대장~비육돈 작업대장 7개가 맞다.
- 대시보드에서 보고서 → 작업대장(모돈리스트·작업지시서 포함)을 누르면 하위 메뉴를 펼치는 동시에 해당 보고서 화면으로 이동하므로, 실제로 보이는 하위 메뉴는 보고서 화면 사이드바다.
- 각 작업대장 하위 탭은 `/reports/work-ledger/<구분>`의 독립 URL을 사용하며 기존 통합 작업대장 기록을 해당 업무로 자동 필터링한다. 초발정대장과 임신진단 사고대장은 각각 저장된 실제 기록을 표시한다.
- 모돈전입대장은 전입일 시작·종료일로 조회하며 정렬기준을 모돈번호, 이각번호, 산차, 품종, 출생일 중 선택하고 오름·내림차순을 지정할 수 있다.
- 모돈전입대장은 현재 조회 결과 전체의 인쇄 출력과 `.xlsx` 다운로드를 지원한다. 엑셀 파일은 화면 조회기간과 정렬조건을 서버에서 다시 적용하고 모돈번호·이각번호·품종·산차·출생일·전입일·전입체중·전입상태·구입처·비고를 포함한다.
- 웅돈전입대장은 모돈전입대장과 동일한 기간조회·정렬·인쇄·엑셀 다운로드 형식을 사용한다. 정렬기준은 웅돈번호, 이각번호, 웅돈구분, 품종, 출생일이다.

- 조회·체크박스 선택 삭제 및 브라우저 `localStorage` 저장

### 도폐사관리

- 전입관리에서 등록된 모돈번호·이각번호를 검색해 개체 선택
- 도폐사 구분: 도태, 폐사, 전출, 판매
- 도폐사 원인: 고령/노산, 번식장애, 지제이상/기립불능, 산자수 저하, 포유성적 저하, 기타
- 도폐사일 필수, 체중·판매처/전출처·판매금액·비고 선택 입력
- 동일 모돈의 도폐사 기록 중복 등록 방지
- 작업일·모돈번호·이각번호 정렬과 오름차순·내림차순 지원
- 조회·체크박스 선택 삭제 및 브라우저 `localStorage` 저장
- 경영관리 수익 자동등록은 현재 연결하지 않음

### 번식관리 공통

- 탭: 교배, 임신사고, 분만, 포유자돈, 이유
- 각 목록은 작업일·모돈번호·이각번호 정렬과 오름차순·내림차순 지원
- 체크박스로 잘못된 기록 선택 삭제

### 교배

- 전입 등록된 모돈번호·이각번호 선택
- 분만예정일은 교배일을 1일차로 한 115일째 자동 계산
- 웅돈번호는 화면과 엑셀 모두 선택 입력
- 엑셀 양식 다운로드와 일괄 업로드

### 임신사고

- 사고원인: 재발, 불임, 유산, 공태, 폐사, 도태
- 모돈 선택 시 최근 교배일 자동 연결
- 사고일만 입력하면 경과일 자동 계산
- 등록·조회·선택 삭제 기록을 브라우저 `localStorage`에 저장하며 임신진단 사고대장과 전체 작업대장에 연결

### 분만

- 분만구분: 정상, 조산, 유도분만, 난산
- 생시도태: 체미, 기형, 기타
- 실산 = 총산 - 미라 - 사산. 최초에는 암에 자동 입력되지만 암·수를 직접 수정할 수 있다.
- 실산 암·수 합계가 자동 실산과 다르면 경고하고 저장하지 않는다.
- 포유개시 = 실산 - 생시도태 합계로 자동 계산
- 분만 화면의 양자전입·양자전출과 상대 모돈 입력 지원
- 엑셀 양식 다운로드와 일괄 업로드

### 포유자돈

- 반드시 최근 분만 기록이 있는 모돈을 먼저 선택한다.
- 구분: 포유자돈폐사, 부분이유, 양자전입, 양자전출
- 포유자돈폐사 원인: 원인불명, 포유중도태, 체중미달, 압사, 설사, 위축, 관절, 기타
- 양자전입·전출 원인: 산자수, 포유중단, 모돈폐사, 재포유모돈, 젖불량, 기타, 포유불능, 사고기록누락
- 현재 포유두수는 분만과 이후 포유자돈 증감 기록을 반영한다.

### 이유

- 반드시 포유 중인 모돈을 먼저 선택한다.
- 분만일과 현재 포유두수 자동 연결
- 이유일령과 이유 후 잔여두수 자동 계산
- 이유두수 암·수, 자돈 평균체중·총체중, 재포유, 양자 이동, 모돈·자돈 이동, 비고 입력
- 참고 화면의 자돈 폐사 입력 영역은 제외
- 이유 후 잔여두수는 0이 아니어도 저장 가능
- 재포유 두수는 잔여두수를 초과할 수 없음
- 전출 모돈과 전입 모돈은 최근 분만 기록이 있는 다른 모돈에서 선택
- 이미 같은 분만 건에 이유 기록이 있으면 선택 및 업로드 중복 방지
- 엑셀 양식 다운로드와 일괄 업로드

## 6. 중요 업무 계산

- 분만예정일: 교배일을 1일차로 하여 115일째
- 자동 실산: `총산 - 미라 - 사산`
- 포유개시: `실산 암 + 실산 수 - 체미 - 기형 - 기타`
- 현재 포유두수: 분만 포유개시와 분만 양자 이동을 반영한 뒤 포유자돈 기록의 전입은 더하고 폐사·부분이유·전출은 뺀다.
- 이유 후 잔여두수: `현재 포유두수 + 이유 화면 양자전입 - 양자전출 - 이유두수`
