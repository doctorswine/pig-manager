# 피그매니저 프로젝트 인수인계

최종 갱신: 2026-09-21

## 1. 제품 방향

- 피그플랜, 피그온, 피그지오와 같은 돼지 농장 전산 프로그램을 만든다.
- 첫 대상은 모돈 중심 번식농장이다.
- 기술 방향은 Next.js App Router, TypeScript, Supabase, Vercel이다.
- 현재는 Supabase 연결 전이며 브라우저 `localStorage`와 예시 데이터로 업무 흐름을 검증하는 프로토타입 단계다.
- 핵심 번식 흐름은 `전입 → 초발정 → 교배 → 임신사고/분만 → 포유자돈 → 이유`다.
- 초기 요청에서 독립적인 양자 사이클은 제외했다. 양자전입·전출은 분만·포유·이유 기록 안의 두수 조정으로 관리한다.

## 2. 실행 방법

```powershell
npm install
npm run build
npm start
```

기본 주소는 `http://localhost:3000`이다. 새 빌드 후 기존 `next start` 프로세스를 종료하고 다시 시작해야 화면에 반영된다.

## 3. 현재 구현된 화면

### 대시보드

- 농장 현황, 관리 필요 항목, 번식 KPI, 월별 추세를 한눈에 보여주는 예시 화면
- 생산관리 1차 메뉴: 모돈개체관리, 웅돈개체관리, 비육돈그룹관리, 출하관리
- 모돈개체관리 세부 메뉴: 전입관리, 초발정관리, 번식관리, 등지방관리, 도폐사관리

### 전입관리

- 모돈번호·이각번호 중복 검사
- 품종: F1, YY, LY, F2, YL, LL, DD, 기타
- 시작상태: 후보돈, 임신돈, 포유돈, 이유모돈, 사고돈, 대리모돈, 유산돈
- 전입 정보 중심 입력. 가계, 전자이표번호, 시작 돈방은 제거됨.
- 엑셀 양식 다운로드와 일괄 업로드
- 조회·정렬·체크박스 선택 삭제

### 초발정관리

- 전입 개체에서 모돈번호·이각번호 선택
- 1차부터 4차까지만 기록
- 시간과 장소는 제외
- 발정일, 체중, 등지방, 발정강도, 비고
- 발정강도: 정상발정, 미약발정, 이상발정, 잦은거부
- 조회·정렬·체크박스 선택 삭제

### 번식관리 공통

- 탭: 교배, 임신사고, 분만, 포유자돈, 이유
- 각 목록은 작업일·모돈번호·이각번호 정렬과 오름차순·내림차순 지원
- 체크박스로 잘못된 기록 선택 삭제

### 교배

- 전입 등록된 모돈번호·이각번호 선택
- 분만예정일은 교배일을 1일차로 한 115일째 자동 계산
- 웅돈번호는 화면과 엑셀 모두 선택 입력
- 엑셀 양식 다운로드와 일괄 업로드

### 임신사고

- 사고원인: 재발, 불임, 유산, 공태, 폐사, 도태
- 모돈 선택 시 최근 교배일 자동 연결
- 사고일만 입력하면 경과일 자동 계산

### 분만

- 분만구분: 정상, 조산, 유도분만, 난산
- 생시도태: 체미, 기형, 기타
- 실산 = 총산 - 미라 - 사산. 최초에는 암에 자동 입력되지만 암·수를 직접 수정할 수 있다.
- 실산 암·수 합계가 자동 실산과 다르면 경고하고 저장하지 않는다.
- 포유개시 = 실산 - 생시도태 합계로 자동 계산
- 분만 화면의 양자전입·양자전출과 상대 모돈 입력 지원
- 엑셀 양식 다운로드와 일괄 업로드

### 포유자돈

- 반드시 최근 분만 기록이 있는 모돈을 먼저 선택한다.
- 구분: 포유자돈폐사, 부분이유, 양자전입, 양자전출
- 포유자돈폐사 원인: 원인불명, 포유중도태, 체중미달, 압사, 설사, 위축, 관절, 기타
- 양자전입·전출 원인: 산자수, 포유중단, 모돈폐사, 재포유모돈, 젖불량, 기타, 포유불능, 사고기록누락
- 현재 포유두수는 분만과 이후 포유자돈 증감 기록을 반영한다.

### 이유

- 반드시 포유 중인 모돈을 먼저 선택한다.
- 분만일과 현재 포유두수 자동 연결
- 이유일령과 이유 후 잔여두수 자동 계산
- 이유두수 암·수, 자돈 평균체중·총체중, 재포유, 양자 이동, 모돈·자돈 이동, 비고 입력
- 참고 화면의 자돈 폐사 입력 영역은 제외
- 이유 후 잔여두수는 0이 아니어도 저장 가능
- 재포유 두수는 잔여두수를 초과할 수 없음
- 전출 모돈과 전입 모돈은 최근 분만 기록이 있는 다른 모돈에서 선택
- 이미 같은 분만 건에 이유 기록이 있으면 선택 및 업로드 중복 방지
- 엑셀 양식 다운로드와 일괄 업로드

## 4. 데이터 파일과 저장 키

| 영역 | 타입·기본 데이터 | localStorage 키 |
| --- | --- | --- |
| 전입 | `app/production/sows/_data/intake-records.ts` | 파일의 상수 확인 |
| 교배 | `app/production/sows/_data/mating-records.ts` | 파일의 상수 확인 |
| 분만 | `app/production/sows/_data/farrowing-records.ts` | `pig-manager:farrowing-records` |
| 포유자돈 | `app/production/sows/_data/nursing-piglet-records.ts` | `pig-manager:nursing-piglet-records` |
| 이유 | `app/production/sows/_data/weaning-records.ts` | `pig-manager:weaning-records` |

중요: 현재 데이터는 브라우저별 `localStorage`에 있으므로 운영 데이터로 사용하면 안 된다. Supabase 전환 시 농장별 격리, RLS, 감사 이력과 정정·취소 방식을 적용한다.

## 5. 엑셀 일괄등록 구조

| 기능 | 다운로드 양식 | 업로드 API |
| --- | --- | --- |
| 전입 | `public/templates/모돈전입등록양식.xlsx` | `app/api/intake/import/route.ts` |
| 교배 | `public/templates/모돈교배등록양식.xlsx` | `app/api/mating/import/route.ts` |
| 분만 | `public/templates/모돈분만등록양식.xlsx` | `app/api/farrowing/import/route.ts` |
| 이유 | `public/templates/모돈이유등록양식.xlsx` | `app/api/weaning/import/route.ts` |

- 업로드 제한: `.xlsx`, 최대 5MB, 최대 1,000행
- 서버는 헤더·날짜·수치·파일 내부 중복을 검사한다.
- 화면은 전입/분만 기록 존재 여부, 현재 두수, 이미 저장된 기록과의 중복을 추가 검사한다.
- 관련 생성·검증 스크립트는 `scripts/`에 있다.

## 6. 중요 업무 계산

- 분만예정일: 교배일을 1일차로 하여 115일째
- 자동 실산: `총산 - 미라 - 사산`
- 포유개시: `실산 암 + 실산 수 - 체미 - 기형 - 기타`
- 현재 포유두수: 분만 포유개시와 분만 양자 이동을 반영한 뒤 포유자돈 기록의 전입은 더하고 폐사·부분이유·전출은 뺀다.
- 이유 후 잔여두수: `현재 포유두수 + 이유 화면 양자전입 - 양자전출 - 이유두수`

## 7. 검증 상태

- `npm run build` 성공
- 이유 업로드 API에 잔여 2두·재포유 2두 예시를 업로드하여 200 응답과 정상 파싱 확인
- 이유 양식 다운로드 HTTP 200 확인
- 이유 화면 브라우저 검증: 업로드/다운로드 버튼, 분만 모돈 후보, 잔여두수 도움말 확인
- 최근 브라우저 콘솔 경고·오류 및 Next.js 오류 오버레이 없음
