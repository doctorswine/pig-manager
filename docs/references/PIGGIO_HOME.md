# 피그지오 첫 화면 참고 분석

## 참고 목적

피그지오의 농장현황 첫 화면에서 한눈에 읽히는 요소와 개선점을 찾아 피그매니저 대시보드 정보 구조에 반영한다. 화면을 그대로 복제하지 않는다.

## 화면 정보 구조

### 전역 탐색

- 좌측 접이식 메뉴: 메인화면, 농장관리, 경영관리, 생산관리, 사육환경관리, 보고서, 매뉴얼
- 상단 즐겨찾기와 사용자 기능
- 우측 상단에 최종 교배일·분만일·이유일 표시

### 중앙 그래프

- 산차별 모돈 구성비
- 사료 구성비
- 이유두수 대비 출하두수
- 분만율 대비 교배복수

### 우측 요약

- 사육일보: 전일·금일·차이
- 농가별 관리대상비율: 초발정, 교배, 분만, 이유, 백신 예정 및 경과두수
- 각 관리 대상에서 상세 목록으로 이동하는 `보기` 버튼

## 잘 작동하는 점

1. 큰 카드와 충분한 여백으로 영역 구분이 명확하다.
2. 산차 구성처럼 구조를 비교하는 데이터는 그래프로 빠르게 읽힌다.
3. 예정두수와 경과두수를 나란히 보여줘 계획 대비 지연을 찾을 수 있다.
4. 최종 작업일을 상단에 고정해 데이터 입력이 멈춘 시점을 확인할 수 있다.
5. 관리 대상에서 상세 목록으로 이동하는 행동 경로가 있다.

## 개선할 점

1. 가장 중요한 지연 작업이 오른쪽 작은 표에 있어 그래프보다 덜 눈에 띈다.
2. 차트가 큰 면적을 차지하지만 목표 이탈이나 조치 필요 여부를 직접 설명하지 않는다.
3. 색상이 항목 구분에는 쓰이나 정상·주의·위험 의미는 일관되지 않는다.
4. 사육일보의 숫자가 많아 번식 담당자에게 필요한 변화가 무엇인지 빠르게 판단하기 어렵다.
5. `보기` 버튼이 반복되며 어떤 목록이 얼마나 긴급한지 표현하지 않는다.
6. 좌측 메뉴와 3열 대시보드는 좁은 화면과 모바일 사용에 적합하지 않다.
7. 두 축을 사용하는 차트는 단위와 관계를 이해하는 데 시간이 걸린다.

## 피그매니저에 반영할 요소

- 상단에 현재 농장, 기준일, 마지막 교배·분만·이유 기록일을 표시한다.
- `예정`, `지연`, `완료`를 한 카드 안에서 비교하고 숫자를 누르면 대상 모돈 목록으로 이동한다.
- 산차별 모돈 구성은 번식 현황의 보조 차트로 유지한다.
- 전일 대비 전체 사육두수 대신 번식 담당자가 조치할 수 있는 변화만 첫 화면에 보여준다.
- 긴급도는 `정상`, `주의`, `지연`의 텍스트와 색상을 함께 사용한다.
- 그래프에는 현재값, 목표값, 차이를 명시한다.

## MVP에서 제외할 항목

- 사료 구성비
- 출하두수 비교
- 백신 예정
- 비육돈과 전체 사육일보

위 항목은 사료·건강·비육·출하 모듈을 구현할 때 추가한다.
