# 피그플랜 첫 화면 참고 분석

## 참고 자료

- 피그플랜 접속 직후 대시보드 화면 2장
- 분석일: 2026-09-19
- 목적: 화면 복제가 아니라 정보 구조와 현장 업무 우선순위 참고

## 화면 정보 구조

### 상단 전역 영역

- 1차 메뉴: 번식돈 관리, 비육돈 관리, 경영관리, 보고서, 농장 정보관리, 시스템 관리
- 미처리 건수 경고
- 최근 교배일, 분만일, 이유일 표시
- 즐겨찾기, 도움말, 사용자/언어 관련 기능

### 왼쪽 업무 영역

`관리대상모돈` 표가 초과일수 구간별로 예외 개체 수를 보여준다.

- 미교배 후보돈
- 이유 후 미교배돈
- 사고 후 미교배돈
- 교배 후 분만 지연돈
- 분만 후 이유 지연돈

그 아래에는 이유 실적을 이용한 월별 출하 예측과 시세 차트가 있다. 출하 예측과 시세는 피그매니저 번식 MVP 범위에서는 제외한다.

### 오른쪽 분석 영역

`주요 생산성 요인 구성도`가 상시모돈수에서 PSY/MSY까지의 관계를 트리 형태로 보여준다.

- 상시모돈수
- PSY, MSY
- 평균 이유두수
- 모돈회전율
- 평균 실산
- 이유 전 폐사율
- 포유기간, 비생산일수, 임신기간
- 교배 후 사고, 사고 후 교배, 이유 후 교배, 사고 후 도폐 기간

아래에는 월별 총산·실산·이유와 분만율·비생산일수 차트가 배치된다.

## 잘 작동하는 점

1. 로그인 직후 처리할 예외와 생산성 결과를 한 화면에서 확인할 수 있다.
2. 단순 KPI 숫자가 아니라 PSY/MSY에 영향을 주는 선행 지표를 계층으로 표현한다.
3. 초과일수를 구간으로 나눠 지연의 심각도를 빠르게 파악하게 한다.
4. 숫자에서 관련 관리 화면으로 이동할 수 있는 구조가 보인다.
5. 실적과 비교 기준을 색상으로 구분해 이상값을 드러낸다.

## 개선할 점

1. 화면 밀도가 높고 글자와 클릭 영역이 작아 모바일 현장 입력에 불리하다.
2. 여러 숫자가 나란히 표시되지만 실제값·목표·평균의 의미를 처음 보는 사용자가 이해하기 어렵다.
3. 업무 경고, 경영 지표, 출하, 시세가 한 화면에 섞여 첫 행동의 우선순위가 흐려진다.
4. 빨강과 파랑의 의미가 카드마다 명확히 설명되지 않는다.
5. 그래프 범례와 날짜가 작고 데이터가 많아 빠른 판독이 어렵다.
6. 미처리 건수만 강조되고 각 건의 긴급도와 담당자 정보는 첫 화면에서 보이지 않는다.

## 피그매니저 반영안

### 첫 화면 구성

```text
┌ 농장 선택 · 날짜 · 빠른 검색 ─────────────────────┐
├ 오늘 할 일 ───────────┬ 번식 현황 ───────────────┤
│ 지연 작업              │ 교배 / 임신 / 분만 / 이유 │
│ 오늘 예정              │ 상태별 모돈 수            │
│ 담당자별 작업          │ 예정 대비 완료            │
├ 관리 필요 모돈 ───────┼ 핵심 KPI ────────────────┤
│ 이유 후 미교배          │ 분만율 / 총산 / 생존 / 이유 │
│ 교배 후 진단 지연       │ 전월·목표 대비             │
│ 분만 예정 초과          │ 추세 보기                  │
│ 이유 예정 초과          │                            │
└ 최근 기록 · 월별 추세 ───────────────────────────┘
```

### 첫 화면에 유지할 지표

- 오늘/지연 작업 수
- 이유 후 미교배 모돈 수와 경과일 구간
- 임신진단 지연 모돈 수
- 분만 예정일 초과 모돈 수
- 이유 예정일 초과 모돈 수
- 기간 내 교배복수, 분만복수, 이유복수
- 분만율, 복당 총산, 복당 생존산자, 복당 이유두수

### 상세 분석 화면으로 이동할 지표

- 모돈회전율
- 비생산일수와 원인별 기간
- PSY 구성요인 트리
- 월별 총산·생존산자·이유 추세
- 농장 목표 및 이전 기간 비교

MSY, 출하 예측, 시세는 비육·출하 기능을 구현하는 후속 단계에서 추가한다.

## UX 원칙

- 데스크톱 대시보드와 모바일 현장 화면의 정보 밀도를 다르게 설계한다.
- 빨강은 조치가 필요한 지연/위험에만 사용한다.
- 실제값 옆에는 `목표`, `전월`, `농장평균`처럼 비교 기준명을 반드시 표시한다.
- 숫자 카드는 해당 모돈 목록이나 원본 기록으로 이동할 수 있어야 한다.
- 기본 화면은 작업 중심, 상세 화면은 분석 중심으로 나눈다.
- 사용자가 요청한 범위에 따라 양자 입력과 양자 지표는 포함하지 않는다.
