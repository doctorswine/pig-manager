## 1. 용어·계산식

### 1.1 모돈수 / 사육일수
- **상시모돈수**: 「산출기간동안 후보돈을 제외한 평균적인 모돈사육두수 = (총모돈사육일수(후보포함) - 후보돈사육일수) / 산출기간일수」 (PP p.233, p.792 부록B-4, p.686)
- **후보돈포함상시모돈수**: 「산출기간동안 평균적인 모돈의 사육두수 = 총모돈사육일수(후보포함) / 산출기간일수」 (PP p.233, 792)
- 용어집 정의: 「상시모돈수: 농장에 일상적으로 있는 모돈의 수(후보돈 제외)」 (PP p.785)
- **총모돈사육일수(후보포함)**: 「산출기간동안 모돈이 살아온 총 날수, 일수의 계산은 시작일을 0으로 하고 끝일을 1로 계산합니다. 예를들어 후보돈이 2006년 12월 31일에 전입하고 2007년 1월 31일에 도태되었다면 12월의 사육일수는 0일이고 1월의 사육일수는 31일입니다.」 (PP p.232, 786)
- **후보돈사육일수**: 「산출기간동안 후보돈으로 전입해서 초교배까지의 살아간 총 날 수, 임신돈으로 전입한 0산차의 임신모돈은 전입후 교배일까지의 기간이 후보돈 사육일수로 잡힙니다.」 (PP p.232)
- **포유일수**: 「산출기간동안 포유돈 상태인 모돈의 총 사육일수로 분만당일은 0일로 계산되고 이유일은 1일로 계산됩니다.」 (PP p.232)
- **임신일수**: 「= 총모돈사육일수 - 후보돈사육일수 - 포유일수 - 총비생산일수」 (PP p.232, 792)
- **모돈생산일수(임신+포유)**: 「임신일수와 포유일수의 합, 재귀발정기간은 생산일수로 계산되지 않습니다.」 (PP p.232)
- 상시모돈 산출 방법은 별도 절이 없습니다. 위 사육일수 방식(일할, 시작일 0·종료일 1)이 유일한 설명입니다. PigGio도 비생산일수분석·번식주기 표에 상시모돈수 / 후보돈포함 상시모돈수를 기간별로 출력합니다(PG p.92 [그림]).
  - [그림] 합계 열은 월별 상시모돈수의 단순합(1,802.2)이고 평균 열은 합계/12(150.2)입니다.

### 1.2 비생산일수(NPD)
- **총비생산일수(후보제외)**: 「모돈이 임신을 하거나 포유를 하지 않고 공밥을 먹고 있는 날 수, 후보돈 사육일 수를 제외한 사고일수(임돈전출, 임돈판매 제외)와 이유후 교배 또는 도폐, 사고후 교배 또는 도폐까지의 기간을 합한 날수」 (PP p.232, 787)
- **후보돈포함총비생산일수**: 「총비생산일수에 후보돈 사육일수를 합한 날수」 (PP p.232)
- **평균비생산일수**: 「후보돈을 제외한 연간 모돈의 평균적인 비생산일수 = 총비생산일수(후보제외) * 365 / (모돈사육일수 - 후보돈사육일수)」 (PP p.232, 247, 792)
- **후보돈포함평균비생산일수**: 「= (총비생산일수(후보제외) + 후보돈사육일수) * 365 / 총모돈사육일수(후보포함)」 (PP p.232, 247, 792)
- 용어집에는 「평균비생산일수(NPD): 총 비생산일수를 상시모돈수로 나눈값」(PP p.785)이라고만 돼 있습니다. 실제 식은 위의 연환산(×365/사육일수)이고, 이는 `총비생산 × 365 / (상시모돈수 × 기간일수)`와 같습니다.
- 임돈전출·임돈판매: 「사고기록이기는 하나 분만율이나 비생산일수에는 영향을 주지 않도록 설계」 (PP p.158). PigPlan 사육일수 보고서에서는 「임돈전출(임신일수)」「임돈판매(임신일수)」로 표시돼 임신일수로 처리됩니다(PP p.292 [그림]).
- 이유후 경과일: 「이유후 경과일수는 모두 비생산일수로 계산됩니다」 (PP p.218)

**비생산일수 구간(세그먼트)**

후보돈전입 ~ 초교배
후보돈전입 ~ 도폐사
이유후 ~ 교배
이유후 ~ 도폐
교배후 ~ 사고
사고후 ~ 교배
사고후 ~ 도폐
후보돈포함 총비생산일수
평균 비생산일수

[추정] 스크린샷 수치로 검증한 관계입니다.
- `임신사고 소계 = 조기재발+1차+불규칙+2차+지연+공태+분만사불임`, `임신사고 합계 = 소계 + 유산 + 도태 + 폐사`. 임돈전출·판매는 행이 없습니다. 예: 853+758+39+148+149+609=2,556이고 2,556+238+53+113=2,960.
- `교배후~사고` 행은 `임신사고 합계`와 매월 같습니다. 즉 사고일수(교배일→사고일)의 합입니다.
- `후보돈포함 총비생산일수 = 후보돈전입~초교배 + 후보돈전입~도폐사 + 이유후~교배 + 이유후~도폐 + 교배후~사고 + 사고후~교배 + 사고후~도폐`. 예: 2072+1303+2491+3220+2960+787+596=13,429 ≈ 13,428.
- `총비생산일수(후보제외) = 후보돈포함 총비생산 − (후보돈전입~초교배 + 후보돈전입~도폐사)`
- 평균 비생산일수 검증: 24-07은 (1307−50−248)=1009 × 365 / (144.3 × 31) = 82.3이고, 후보포함은 1307 × 365 / (153.9 × 31) = 100.0입니다.
- 비율(%) 열: 임신사고 세부행은 임신사고 합계 대비(853/2960=28.8), 세그먼트 행은 후보돈포함 총비생산일수 대비(2072/13428=15.4)입니다.
- 구간 일수는 기간별로 일할 배분되는 것으로 보입니다. 후보돈전입~도폐사가 24-06/07/08에 240/248/248(=8두×30/31/31일)이므로, 아직 진행 중인 상태도 기간 종료일까지 일수가 잡힙니다.

PigPlan 사육일수분석 > 비생산일수 그래프 범례(PP p.293 [그림])는 공태, 유산, 폐사, 후보전입~도폐, 이유후~교배, 이유후~도폐, **이유후~**, 사고후~교배, 사고후~도폐, **사고후~**, **후보전입~**, 후보전입~초교배, 도태, 분만사불임, 지연재발, 2차재발, 불규칙재발, 1차재발, 조기재발입니다.
- PigPlan은 진행 중 구간을 별도 세그먼트로 구분합니다. "이유후~"는 기간말 현재 이유 후 미교배, "사고후~"는 사고 후 미처리, "후보전입~"는 아직 미교배 후보돈을 뜻합니다 [추정]. PigGio 표에는 "~"로 끝나는 행이 없습니다.

### 1.3 모돈회전율 / PSY / MSY
- **모돈회전율(LSY)**: 「후보돈을 제외한 모돈이 일년에 생산 사이클을 몇 번 도는가를 나타내는 지수 = (임신일수 / (총모돈사육일수(후보포함) - 후보돈사육일수)) * 365 / 평균임신기간」 (PP p.232, 249, 792, 686)
  - 분모는 `(총모돈사육일수(후보포함) − 후보돈사육일수)`, 즉 상시모돈수 × 기간일수입니다. 평균임신기간은 해당 기간 분만모돈의 실측값입니다(`SUM(분만일-교배일)/분만복수`).
  - [추정·검증] PG 번식주기 22-04: (3035 / (4947−262)) × 365 / 116.4 = 2.03 ✓ (PG p.106 [그림]). 분만이 없는 기간은 평균임신기간이 없어 회전율이 빈칸으로 나옵니다(PG p.92, 24-08 열).
- **후보돈포함모돈회전율**: 「= (임신일수 / 총모돈사육일수(후보포함)) * 365 / 평균임신기간」 (PP p.232, 792)
- PigPlan 작업예정돈의 개체 '회전율'은 다른 정의입니다: 「365일을 평균분만간격(전분만일에서 다음분만일까지의 기간의 평균값)으로 나눈 값」 (PP p.207)
- **PSY**: 「복당평균이유두수에 모돈회전율을 곱한 값 = ((임신일수 * 총이유자돈수) / ((총모돈사육일수(후보포함) - 후보돈사육일수) * 이유복수)) * 365 / 평균임신기간」 (PP p.232, 248)
- **후보돈포함PSY**: 「= ((임신일수 * 총이유자돈수) / (총모돈사육일수(후보포함) * 이유복수)) * 365 / 평균임신기간」 (PP p.232)
- **PSY(대모제외)**: 「((임신일수) * (총이유자돈수)) / ((총모돈사육일수-후보돈사육일수) * (대모돈제외이유복수)) * 365 / (평균임신기간)」 (PP p.232, 792). 스마트피그플랜 경영보고서의 PSY는 이 식입니다(PP p.686).
- PSY에는 평균이유두수(이유모돈 기준)가 아니라 복당평균이유두수(이유복수 기준)가 쓰입니다(PP p.282).
- **MSY**: 「총출하두수 * 365/ 총모돈사육일수」 (PP p.232, 251, 792). 출하두수는 「거래기록에 등록된 총 출하두수」입니다.
- PigGio에는 Original PSY(OPSY) 항목이 따로 있고, 상시모돈수 기준일(기본 120)을 생산기초정보에서 바꿀 수 있습니다(PG p.22, 107, 108). OPSY 계산식은 **[불명확]**입니다.

### 1.4 교배 관련
- **교배복수**: 「기간동안 교배 기록한 모돈수」 (PP p.227)
- 1회/2회/3회 교배복수는 웅돈 1회만 / 1·2회 / 3회까지 교배한 경우입니다.
  - 「교배복수 = 1회교배복수 + 2회교배복수 + 3회교배복수 = 순자연교배 + 순인공교배 + 혼합교배 = 정상교배 + 1차재발교배 + 2차재발교배 + 기타사고후교배 = 미경산돈교배복수 + 경산돈교배복수」 (PP p.227)
  - 3회이상교배비율 = 3회교배복수×100/교배복수, 2회교배복수비율 = 100 − 1회비율 − 3회이상비율
- **정상교배**: 「교배차수(한 산차에서 교배기록수)가 1인 교배복수」 (PP p.227)
- **1차재발교배**: 「사고원인이 '재발불임'으로 입력되고, 교배일에서 사고일까지의 사고일수가 26일보다 작았던 모돈을 다시 교배한 교배복수」 (PP p.227)
- **2차재발교배**: 「…'재발불임'…사고일수가 26일에서 46일 사이인 모돈을 다시 교배한 교배복수」 (PP p.227)
- **기타사고후교배**: 「사고원인이 '유산'으로 입력되거나, '재발불임'으로 등록되고 교배일에서 사고일까지의 사고일수가 46일보다 큰 모돈을 다시 교배한 교배복수」 (PP p.227–228)
- **미경산/경산 재발교배**: 「'재발불임'…사고일수가 47일보다 작은 모돈을 다시 교배한 교배복수」. 기타사고후교배는 위와 같이 유산 또는 재발불임 >46일입니다(PP p.228).
  - 미경산 = 산차 0, 경산 = 「분만한 경험이 있고(산차가 0 이상)」라고 적혀 있습니다(원문 그대로이며 '1 이상'의 오기로 보임 **[불명확]**).
- 재발교배비율: 「재발교배두수 * 100 / 총교배두수」 (PP p.229)
- **초교배복수(모돈편입)**: 출생 후 처음 교배한 모돈수 (PP p.228)
- **평균초교배일령**: 「출생 후 첫 교배한 모돈들의 출생일에서 첫 교배일까지의 평균기간 = SUM(초교배일 - 출생일) / 초교배복수」 (PP p.228, 791)
- 평균전입교배간격: 「SUM(초교배일 - 전입일) / 초교배복수」 (PP p.233)
- **재귀발정계산교배모돈수**: 「경산돈정상교배 중에서 반드시 이전 이유기록이 있는 모돈수」 (PP p.228)
- 재귀일 계산 범위: 「재귀일은 산차가 0 이상이고, 이유후의 첫교배시에만 계산되며 교배차수가 1 보다 크면 계산되지 않습니다.」 (PP p.193–194, 교배대장 항목설명). 같은 곳에 「초교배일은 후보돈의 첫 교배일 때만 계산되며(산차가 0-1일때) 괄호안에 표시됩니다」라고 돼 있습니다.
- **총재귀일수** = 「SUM(교배일 - 이유일)」, **평균재귀발정일령** = 「총재귀일수 / 재귀발정계산교배모돈수」 (PP p.228, 240)
- **3일내재귀복수**: 「이유일에서 교배일까지 기간이 3일 이하인 정상교배 모돈수」
- 4일~9일 재귀복수는 각각 해당 일수인 정상교배 모돈수이고, 10일이상재귀복수는 10일 이상입니다(PP p.228–229).
- **7일내재귀율**: 「(3일내재귀복수 + 4일재귀복수 + 5일재귀복수 + 6일재귀복수 + 7일재귀복수) * 100 / 재귀발정계산교배모돈수」 (PP p.229)
- **4~6일재귀율**: 「(4일재귀복수 + 5일재귀복수 + 6일재귀복수) * 100 / 재귀발정계산교배모돈수」 (PP p.229)

### 1.5 임신사고 구분과 일수 구간
- 임신사고구분 입력값은 「재발불임, 유산, 도태, 폐사, 임돈전출, 임돈판매」입니다(PP p.158).
  - 「수태가 되지 않은 경우는 모두 재발불임으로 입력하면 교배성적의 [재발정분석] 보고서에서 일자별로 임신사고를 분석해 줍니다.」
- 경과일(사고일수) = 교배일 → 임신사고일입니다. 「경과일이 비정상적으로 크면(115일보다 크면)」 기록 오류를 의심합니다(PP p.158).
- 도폐사판매 기록만 하면 임신사고기록이 자동 생성됩니다(PP p.158).
- **불임 일수 구간(용어집, PP p.782 부록A-6)**

| 구분 | 교배후 일수 |
|---|---|
| 조기재발 | 0~17일 |
| 1차재발 | 18~25일 |
| 불규칙재발 | 26~37일 |
| 2차재발 | 38~46일 |
| 지연재발 | 47~80일 |
| 공태 | 81~106일 |
| 분만사불임 | 107~사고일 |

  - PigPlan 사육일수 보고서의 행 라벨도 같습니다: 조기재발(0-17일), 1차재발(18-25일), 불규칙재발(26-37일), 2차재발(38-46일), 지연재발(47~80일), 공태(81~106일), 분만사불임(107일~) (PP p.292 [그림])
  - PigPlan 임신사고원인분석의 일수별 행은 0~17, 18~25, 26~37, 38~46, 47~80, 81~106, 107일이상입니다(PP p.266 [그림]).
- 분만예정돈 중 사고 분류(생산성적, PP p.229)
  - 임신사고1차재발: 재발불임 & 18~25
  - 임신사고2차재발: 재발불임 & 38~46
  - 임신사고기타재발: 「재발불임이고 사고일수가 18일 미만이거나 47일 이상」
  - **[불명확]** 이 정의대로면 26~37일(불규칙재발)이 어느 분류에도 들어가지 않습니다.
- **[불명확]** 일수 경계가 문서마다 다릅니다. 재발교배 분류는 <26 / 26~46 / >46이고, 재발정분석 보고서 열은 17이하 / 18-24 / 25-38 / 39-45 / 46-108입니다(§2.1.4).
- 용어집 「재발(정): 모돈이 교배를 하였으나 임신이 되지 않고 다시 발정이 오는 경우」 (PP p.780)

### 1.6 분만
- **분만예정일**: 「교배일로부터 115일 이후의 날짜」(PP p.782), 「교배일에서 임신기간(115일)을 더해서 계산」(PP p.220)
  - PigGio: 「농장에서 설정한 평균임신기간에 따라 분만예정일이 계산됩니다」 (PG p.83, 84)
- **분만예정복수**: 「분만복수에 산출기간 115일(…평균임신기간) 전에 교배하였으나 이후 임신사고 난 모돈수를 더한 값 = 분만복수 + 분만예정돈임신사고복수」 (PP p.229). PigGio: 「분만예정복수 = 분만복수 + 분만예정돈사고복수」 (PG p.90, 91)
- **분만예정돈임신사고복수**: 「= 임신사고1차재발 + 임신사고2차재발 + 임신사고기타재발 + 유산(예정돈중) + 도태(예정돈중) + 폐사(예정돈중) + 임돈전출(예정돈중) + 임돈판매(예정돈중)」 (PP p.229)
- **분만율**: 「(분만복수 + 임돈전출 + 임돈판매) * 100 / (분만복수 + 분만예정돈임신사고복수)」. 「사고로 잡히는 임신돈의 전출과 판매는 분만한 것으로 간주」 (PP p.229, 245)
- **보정분만율**: 「(분만복수 + 임돈전출 + 임돈판매) * 100 / (분만복수 + 분만예정돈임신사고복수 - 도태 - 폐사)」 (PP p.229)
- **수태율(46일까지)**: 「교배후 46일까지 임신사고기록이 되지 않은 비율 = (100 - 분만예정돈임신사고복수) * 100 / (분만복수 + 분만예정돈임신사고복수)」 (PP p.230, 791)
  - **[불명확]** 식이 원문 그대로입니다. 「(100 − 사고복수)」는 오기로 보입니다. 의도는 (분만예정복수 − 46일이내 사고복수)×100/분만예정복수일 가능성이 높으나 매뉴얼로는 확인되지 않습니다.
- 평균임신기간 = SUM(분만일-교배일)/분만복수
- 평균분만간격 = SUM(분만일-전산차분만일)/분만복수. 번식주기 정의에서는 분모가 전산차분만모돈수입니다(PP p.231). [추정] PG 번식주기 총분만간격 4443/평균 164.6이면 분모는 27, 분만모돈 28이므로 전산차분만모돈수가 분모입니다.
- 평균총산 = (실산+미라+사산)/분만복수, 평균실산 = 실산/분만복수
- 사산율 = 사산×100/총산, 미라율 = 미라×100/총산
- 복당임신사고일수 = SUM(사고일-교배일)/분만예정돈임신사고복수
- 기간중교배두수: 「산출기간 115일(…평균임신기간)전에 교배한 모돈수」 (PP p.231)

### 1.7 이유
- **평균이유일령(대리모제외)**: 「산출기간동안 정상 이유한 모돈들의 포유기간의 평균값 = SUM(이유일 - 분만일) / 이유모돈두수」 (PP p.230)
  - 용어집 「이유일령: 젖을 먹인 기간. 분만일에서 이유일 사이의 기간」 (PP p.784)
- 평균복당포유기간 = 총포유기간 / 이유복수. 「평균이유일령(대리모제외)과는 다른값이 나올 수 있습니다」 (PP p.231)
- 이유모돈두수: 「부분이유와 대리포유후 이유한 모돈은 제외」. 이유복수(대리모포함)는 「부분이유를 제외한 모돈의 이유기록수. PSY를 계산할 때 이용됨」 (PP p.230)
- 평균이유두수 = 총이유자돈수/이유모돈두수. 복당평균이유두수 = 총이유두수/이유복수(대리모이유포함) (PP p.282)
- 이유전폐사율(기간중) = 100 − (총이유자돈수×100/(총이유자돈수+총입력자돈폐사두수))
- 이유전폐사율(실산대비이유) = 100 − (총이유두수×100)/총실산 (PP p.231)
- 이유두수 = 실산 + 양자전입 − 양자전출 − 포유중사고 (PP p.793)

### 1.8 도폐사·회전
- 모돈도태율 = 「도태모돈수 / 상시모돈수 * 365 / 기간일수」
- 모돈폐사율 = 「폐사모돈수 / 상시모돈수 * 365 / 기간일수」
- 모돈전입율 = 「전입모돈수 / 상시모돈수 * 365 / 기간일수」
- **모돈도폐사율** = 「(도태모돈수 + 폐사모돈수) / 상시모돈수 * 365 / 기간일수」 (PP p.233, 250, 793)
- 기초모돈재고(후보제외) = 시작일 기준, 기말모돈재고두수 = 종료일 기준(후보 제외). 기초/기말후보돈도 같은 방식입니다(PP p.233).
- 총도폐사판매모돈수: 「산출기간 동안 농장을 나간 모돈수」. 도태모돈평균산차: 「산출기간 동안 도태 폐사 판매된 모돈의 평균산차」 (PP p.233)

### 1.9 교배그룹
- PigPlan 작업예정돈의 '그룹': 「최종교배한 날짜를 년도와 주차로 표시하여 보여줍니다. 주차는 1주차부터 52주차 사이의 값이 나타납니다.」 (PP p.207)
- 관리대상모돈의 '그룹'은 [모돈그룹설정]에서 등록한 그룹명으로, 위와 다른 개념입니다(PP p.215).
- 교배그룹별생산성적에서는 교배일 구간(단위 1주 → 7일씩)이 그룹입니다. 그룹 라벨은 "04-1 to 2" 형식(연-주차)이고, 7일 구간은 기간선택 시작일부터 끊습니다(2004-01-01~01-07, 01-08~01-14…) (PP p.264 [그림]).

## 2. 보고서별 정리

### 공통 조회조건
- **PigPlan**: 기간수(기본 12) × 단위(기본 1월)입니다.
  - 「기간수와 단위를 설정한 후 산출기간 시작일을 선택하면 종료일은 자동으로 바뀝니다」. 계절별(3월 단위), 주단위, 일단위도 가능합니다(PP p.226).
  - 출력구분은 기간별 / 산차별 / 품종별이고, 출력항목은 전체 / 기본형 / 핵심형1 / 핵심형2([목표설정]의 사용여부, PP p.82)입니다.
  - 표 열 = 각 기간 시작일(예: 09-10-01) + 합계 + 평균 + 목표값(PP p.252 [그림])
- **PigGio**: 「기간: 몇번으로 나누어서 볼 것인지… 기본설정값은 12」, 「단위: 1달 합계 → 1, 월 / 주차별 → 1, 주」, 「조회기준일: 보고서를 조회하는 가장 마지막 일자」 (PG p.89 등 모든 기간형 보고서)
  - 즉 조회기준일에서 거꾸로 기간×단위만큼 거슬러 올라갑니다. 예: 기준일 2024-08-31, 12×1월이면 2023-09-01~2024-08-31.
  - 열 = YY-MM + 합계 + 평균 + 비율(%)
  - [그림] 평균 = 합계/기간수. 단 평균재귀일 같은 평균형 지표는 합계 열에 월별 평균의 단순합이 찍히기도 합니다(교배실적 평균재귀일 합계 125.2, 초교배일령별 평균총산 합계 91.1). PigPlan 초교배일령별 합계 열은 가중 평균값(10.6)입니다.

### 2.1 교배

#### 2.1.1 교배실적 (기간별/시계열)
- **PP p.252** (6.4.5.1). 출력구분(기간별…), 출력항목(핵심형1 등), 기간수, 단위, 기간선택. 열은 기간·합계·평균·목표값입니다. 항목 정의는 생산성적(PP p.227–229)을 따릅니다.
  - [그림] 핵심형1 행: 교배복수, 초교배복수(모돈편입), 평균초교배일령, 평균재귀발정일령, 8일재귀복수, 9일재귀복수, 7일내재귀율
- **PG p.89** (7.4.1). 조건은 기간 / 단위 / 조회기준일이고, 「해당하는 기간에 입력된 교배기록을 분석합니다」(= 교배일 기준). 행 구성 [그림]:
  - 교배복수
