# 피그매니저 첫 화면 요구사항

## 목표

사용자가 로그인 후 5초 안에 아래 질문에 답할 수 있어야 한다.

1. 어느 농장을 보고 있는가?
2. 오늘 반드시 해야 할 작업은 몇 건인가?
3. 이미 지연된 모돈은 몇 두인가?
4. 최근 교배·분만·이유 기록이 정상적으로 입력되고 있는가?
5. 현재 번식 성적이 목표보다 좋아졌는가, 나빠졌는가?

## 정보 우선순위

### 1순위 — 즉시 조치

- 지연 작업 총수
- 오늘 예정 작업 총수
- 이유 후 미교배
- 임신진단 지연
- 분만 예정일 초과
- 이유 예정일 초과

각 숫자는 필터가 적용된 모돈 목록으로 연결한다.

### 2순위 — 현재 번식 현황

- 후보돈
- 공태돈
- 교배돈
- 임신돈
- 포유돈
- 이유돈
- 최근 교배일·분만일·이유일

### 3순위 — 생산성 결과

- 분만율
- 복당 총산자수
- 복당 생존산자수
- 복당 이유두수
- 이유 전 폐사율
- 이유 후 첫 교배 간격

각 KPI에는 현재값과 함께 `농장 목표` 또는 `이전 기간` 중 하나의 비교 기준을 표시한다.

### 4순위 — 추세와 구조

- 최근 6개월 교배·분만·이유 복수
- 산차별 모돈 구성
- 월별 총산·생존산자·이유두수
- 비생산일수 원인 분석

## 데스크톱 배치

```text
┌ 현재 농장 · 기준일 · 마지막 기록일 · 모돈 검색 ──────────────┐
├ 지연 작업 ───┬ 오늘 예정 ───┬ 완료 ───────┬ 빠른 기록 ─────┤
├ 관리 필요 모돈 목록 ─────────┬ 번식 상태별 모돈 수 ─────────┤
├ 핵심 KPI 4개 ───────────────────────────────────────────────┤
└ 최근 6개월 추세 ──────────────┬ 산차별 모돈 구성 ───────────┘
```

## 모바일 배치

1. 고정 상단: 농장 선택과 모돈 검색
2. 지연 작업 경고
3. 오늘 작업 카드
4. 큰 `기록하기` 버튼
5. 관리 필요 모돈 목록
6. 핵심 KPI 가로 스크롤
7. 상세 차트

## 시각 규칙

- 한 화면에서 강조색은 기본 행동색과 위험색 두 계열만 사용한다.
- 빨강은 기한이 지난 조치 대상에만 사용한다.
- 숫자만 색칠하지 않고 `지연 10두`, `목표 대비 -2.1`처럼 의미를 함께 쓴다.
- 카드 제목은 현장 용어로 쓰고 기술 용어와 영문 약어는 보조 설명으로 둔다.
- 첫 화면의 차트는 최대 2개만 동시에 보여준다.
- 표의 기본 행 높이는 터치하기 충분하게 하고 작은 `보기` 버튼을 반복하지 않는다.
- 데이터가 없을 때는 빈 차트 대신 다음 입력 행동을 안내한다.

## 상호작용 규칙

- 모든 요약 숫자는 상세 목록으로 이동할 수 있다.
- 선택한 기간과 농장은 상세 화면에서도 유지된다.
- 지연 목록은 긴급도, 예정일, 모돈번호, 위치, 담당자를 보여준다.
- 빠른 기록은 교배, 임신진단, 분만, 이유만 제공한다.
- 양자 기능은 포함하지 않는다.

## 첫 화면 완료 기준

- 1366px 이상 데스크톱과 390px 모바일에서 핵심 행동이 스크롤 전에 보인다.
- 사용성 점검에서 신규 사용자가 도움 없이 지연 모돈 목록을 열 수 있다.
- KPI의 현재값과 비교 기준을 혼동하지 않는다.
- 색상을 보지 않아도 정상·주의·지연 상태를 구분할 수 있다.
