# 생산관리 모듈

## 확정된 1차 구조

생산관리는 다음 네 영역으로 구성한다.

1. 모돈개체관리
2. 웅돈개체관리
3. 비육돈그룹관리
4. 출하관리

## 메뉴 구조

```text
생산관리
├─ 모돈개체관리
│  ├─ 전입관리
│  ├─ 초발정관리
│  ├─ 번식관리
│  ├─ 등지방관리
│  └─ 도폐사관리
├─ 웅돈개체관리
├─ 비육돈그룹관리
└─ 출하관리
```

## 현재 결정 범위

- 네 영역을 생산관리의 고정 1차 메뉴로 사용한다.
- 각 영역의 세부 메뉴, 화면, 입력 항목과 업무 규칙은 추후 확정한다.
- 세부 사항이 정해지기 전에는 기능이나 데이터 항목을 임의로 추가하지 않는다.
- 데스크톱에서는 펼침형 사이드바, 모바일에서는 한 단계씩 진입하는 목록으로 제공한다.

## 세부 설계 대기 항목

### 모돈개체관리

- 전입관리
- 초발정관리
- 번식관리
- 등지방관리
- 도폐사관리
- 대상 개체 범위 미정
- 등록·조회·수정 흐름 미정

#### 전입관리

- 상단: 신규 모돈 전입 등록
- 하단: 전입일과 모돈번호 기반 전입 이력 조회
- 전입정보: 모돈번호, 이각번호, 품종, 출생일, 전입일, 최종 작업일, 구입처, 시작상태, 전입체중, 시작산차, 교배차수, 비고
- 필수항목: 모돈번호, 품종, 출생일, 전입일, 시작상태, 시작산차
- 품종 선택값: F1, YY, LY, F2, YL, LL, DD, 기타
- 시작상태 선택값: 후보돈, 임신돈, 포유돈, 이유모돈, 사고돈, 대리모돈, 유산돈
- 현재는 예시 데이터와 화면 내 임시 저장으로 동작하며 Supabase 연결 후 영구 저장 예정

### 웅돈개체관리

- 세부 메뉴 미정
- 개체 정보와 생산 기록 범위 미정

### 비육돈그룹관리

- 세부 메뉴 미정
- 그룹 생성·이동·두수 관리 방식 미정

### 출하관리

- 세부 메뉴 미정
- 출하 계획·실적·정산 범위 미정

## 설계 원칙

- 첫 화면에서 네 영역이 한눈에 구분되어야 한다.
- 현재 선택한 영역과 세부 메뉴 위치가 명확해야 한다.
- 사용 빈도가 높은 기능은 각 영역 첫 화면에서 바로 실행할 수 있어야 한다.
- 영역별 세부 기능은 사용자 확인 후 순차적으로 확정한다.
