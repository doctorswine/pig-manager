# 피그매니저 제품 정의서

## 1. 제품 한 줄 정의

피그매니저는 모돈 중심 번식농장의 후보돈 편입부터 교배·임신진단·분만·이유·도태까지를 현장에서 기록하고 생산 지표와 예정 작업으로 바꾸어 주는 다중 농장 관리 서비스다.

## 2. 주요 사용자

| 역할 | 주요 업무 | 기본 권한 |
| --- | --- | --- |
| 소유자 | 농장 설정, 사용자 초대, 전체 지표 확인 | 조직 전체 관리 |
| 관리자 | 개체·그룹·작업·재고 관리, 보고서 확인 | 지정 농장 관리 |
| 현장 작업자 | 예정 작업 확인, 이벤트 빠른 입력 | 지정 농장 입력/조회 |
| 수의사·컨설턴트 | 건강·생산 지표 검토 | 지정 농장 읽기 중심 |

## 3. MVP 범위

### 계정과 농장

- 이메일 로그인
- 조직, 농장, 돈사/구역 관리
- 사용자 초대와 역할 관리
- 농장별 데이터 격리

### 번식돈 개체

- 모돈·웅돈 개체 등록
- 이력번호, 이각/전자태그, 품종, 생년월일, 도입일, 상태
- 후보돈, 공태, 교배, 임신, 포유, 이유, 도태 상태 관리
- 돈사/돈방 이동 이력

### 번식 이벤트

- 후보돈 편입
- 발정, 교배, 임신진단
- 분만: 총산, 생존, 사산, 미이라
- 이유: 이유두수, 이유일령, 이유체중
- 재귀발정, 유산, 도태, 폐사
- 자돈은 MVP에서 개체별이 아니라 복 단위 두수로 관리

### 작업과 알림

- 교배 후 임신진단 예정일
- 분만 예정일
- 이유 예정일
- 백신·치료·재고 점검 작업
- 담당자 배정과 완료 처리

### 대시보드와 보고서

- 오늘 할 일과 지연 작업
- 교배·분만·이유 현황
- 분만율, 복당 총산/생존/이유두수
- 이유 후 재귀발정 일수
- 폐사·도태 현황

## 4. MVP 이후

- 자돈·육성돈·비육돈 그룹과 두수 이동
- 사료 입출고와 사료요구율
- 약품·백신 재고, 휴약기간
- 환경 센서, 급이기, 저울 연동
- 출하, 도체 성적, 정산
- 회계·원가와 농장 간 벤치마킹
- 오프라인 입력 및 자동 동기화

## 5. 핵심 도메인 원칙

1. 현재 상태만 저장하지 않고 사건(event)을 이력으로 남긴다.
2. 모든 업무 데이터는 `organization_id`와 `farm_id`를 통해 소유 범위가 명확해야 한다.
3. 원본 생산 기록은 물리 삭제하지 않고 취소·정정 이력을 남긴다.
4. 두수 변화는 원인을 가진 거래로 기록하여 현재 두수와 항상 대사할 수 있어야 한다.
5. 날짜와 시간은 DB에서 UTC로 저장하고 화면에서는 농장 시간대로 표시한다.
6. 민감한 권한 판정은 사용자 수정이 가능한 메타데이터에 의존하지 않는다.

## 6. 초기 핵심 엔터티

| 영역 | 엔터티 |
| --- | --- |
| 권한 | organizations, profiles, memberships, farms |
| 시설 | barns, pens |
| 개체 | animals, animal_identifiers, animal_status_events |
| 번식 | breeding_events, pregnancy_checks, farrowings, litter_adjustments, weanings |
| 그룹(후속) | pig_groups, group_movements, group_inventory_transactions |
| 건강 | health_events, treatments, medications |
| 운영 | tasks, task_assignments, attachments, audit_logs |

## 7. 보안 기준

- 공개 스키마의 모든 테이블에 RLS를 활성화한다.
- 인증된 사용자라는 사실만으로 접근을 허용하지 않고 농장 멤버십을 함께 확인한다.
- 프런트엔드에는 Supabase publishable key만 제공한다.
- secret/service-role key는 브라우저 번들에 절대 포함하지 않는다.
- 변경 이력과 중요 관리 작업을 감사 로그에 남긴다.
- 첨부 파일도 조직/농장 경로와 Storage 정책으로 격리한다.

## 8. MVP 완료 기준

한 농장의 관리자가 사용자를 초대하고, 돈사와 모돈을 등록한 뒤 교배부터 분만·이유까지 기록하며, 작업자가 휴대폰에서 오늘의 예정 작업을 완료하고, 관리자가 생산 지표를 확인할 수 있어야 한다.

## 9. 확정된 제품 방향

- 첫 대상: 모돈 중심 번식농장
- 첫 관리 단위: 번식돈은 개체, 포유자돈은 복 단위 두수
- 첫 핵심 사이클: 후보돈/모돈 등록 → 교배 → 임신진단 → 분만 → 이유
- 첫 화면 우선순위: 오늘 할 일, 빠른 기록, 모돈 카드, 번식 현황
- 그룹·비육·출하·사료·회계는 번식 MVP 이후로 연기

## 10. 생산관리 1차 메뉴

- 모돈개체관리
- 웅돈개체관리
- 비육돈그룹관리
- 출하관리

각 영역의 세부 기능은 사용자 확인 후 별도로 확정한다.
