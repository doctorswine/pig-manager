# 모돈 번식농장 사용자 흐름

## 1. 첫 설정

1. 소유자가 계정을 만든다.
2. 조직과 농장을 등록하고 농장 시간대를 선택한다.
3. 돈사와 돈방을 등록한다.
4. 관리자와 현장 작업자를 초대하고 담당 농장을 지정한다.
5. CSV 또는 직접 입력으로 기존 모돈을 등록한다.

## 2. 현장 작업자의 하루

1. 로그인하면 `오늘 할 일`이 가장 먼저 보인다.
2. 임신진단, 분만 예정, 이유 예정, 미완료 작업을 확인한다.
3. 모돈 번호·이각·전자태그로 개체를 찾거나 작업 목록에서 선택한다.
4. 하단의 큰 `기록` 버튼으로 교배·임신진단·분만·이유를 입력한다.
5. 저장 직후 모돈 상태와 다음 예정일이 갱신된 것을 확인한다.

## 3. 교배 기록

필수 입력:

- 모돈
- 교배 일시
- 교배 차수
- 웅돈 또는 정액 코드
- 작업자

선택 입력:

- 발정 확인 일시
- 교배 방법
- 메모

저장 결과:

- 모돈 상태를 `교배`로 변경
- 농장 설정에 따라 1차/2차 임신진단 작업 생성
- 평균 임신기간을 기준으로 분만 예정일 계산

## 4. 임신진단 기록

필수 입력:

- 대상 교배
- 진단일
- 결과: 양성, 음성, 재검, 유산 의심

저장 결과:

- 양성: 상태를 `임신`으로 변경하고 분만 예정 작업 유지
- 음성: 상태를 `공태`로 변경하고 분만 예정 작업 취소
- 재검: 재검 예정 작업 생성

## 5. 분만 기록

필수 입력:

- 분만일시
- 총산자수
- 생존자돈수
- 사산수
- 미이라수

검증 규칙:

- 모든 두수는 0 이상의 정수
- `총산자수 = 생존자돈수 + 사산수 + 미이라수 + 기타수`
- 해당 교배 이후 하나의 유효한 분만 기록만 허용

저장 결과:

- 산차 증가
- 모돈 상태를 `포유`로 변경
- 이유 예정 작업 생성
- 복 단위 현재 포유두수를 생존자돈수로 시작

## 6. 이유 기록

필수 입력:

- 이유일
- 이유두수

선택 입력:

- 총 이유체중 또는 평균 이유체중
- 이유 후 이동 위치

검증 규칙:

- 이유두수는 현재 포유두수를 초과할 수 없음
- 동일 복에 유효한 최종 이유 기록은 하나만 허용

저장 결과:

- 모돈 상태를 `이유`로 변경
- 복을 종료
- 다음 발정 확인 작업 생성

## 7. 기록 정정

- 운영 기록은 화면에서 물리 삭제하지 않는다.
- 잘못된 기록은 취소 사유와 함께 무효화하고 정정 기록을 새로 만든다.
- 정정 전후 값, 작업자, 시각을 감사 로그에 남긴다.
- 취소나 정정 시 파생 상태와 예정 작업을 다시 계산한다.

## 8. 첫 내비게이션 구조

| 메뉴 | 핵심 화면 |
| --- | --- |
| 홈 | 오늘 할 일, 지연 작업, 핵심 경보 |
| 모돈 | 목록, 검색/필터, 개체 카드, 전체 이력 |
| 번식 | 교배, 임신진단, 분만, 이유 현황 |
| 작업 | 예정/지연/완료 작업, 담당자 배정 |
| 보고서 | 주간 교배·분만·이유, 핵심 생산지표 |
| 설정 | 농장, 돈사/돈방, 사용자, 기준일 설정 |
